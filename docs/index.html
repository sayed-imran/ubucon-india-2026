UbuCon India 2026 · Workshop setup

Scaling Local AI: Benchmarking vLLM and Building Personal Agents

Get your laptop ready before the workshop, on a good internet connection. Follow the steps in order and check each one worked before moving on. On the day you only run npm run dev.

Pick your operating system. Every step below changes to match it.

  1. Install nvm (Node Version Manager)

    nvm installs Node.js for your user only, so the workshop's Node version never clashes with anything else on your laptop.

    Open a Terminal (Ctrl+Alt+T on Ubuntu). Make sure curl and git are installed:

    sudo apt update && sudo apt install -y curl git

    Fedora: sudo dnf install -y curl git · Arch: sudo pacman -S curl git

    Install nvm from its latest release (v0.41.0). No sudo here:

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.41.0/install.sh | bash

    Close the terminal and open a new one. nvm only loads in terminals opened after the install.

    Check it worked:

    nvm --version

    Expected: 0.41.0

    Open Terminal (⌘+Space, type “Terminal”). First make sure Apple's Command Line Tools are installed. They provide git:

    xcode-select --install

    If a window opens, click Install and wait for it to finish. If it says the tools are already installed, you're good.

    Install nvm from its latest release (v0.41.0). No sudo here:

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.41.0/install.sh | bash

    Quit Terminal (⌘+Q) and open it again. nvm only loads in terminals opened after the install.

    Check it worked:

    nvm --version

    Expected: 0.41.0. If you see “nvm: command not found”, see troubleshooting.

    Download the installer from the official NVM for Windows release (v2.0.1, the latest stable release):

    Download for most laptopsnvm-2.0.1-x64-setup.exe ARM laptops (Snapdragon)nvm-2.0.1-arm64-setup.exe

    Not sure which one? Settings → System → About → System type. “x64-based processor” means the first one. You need the -setup.exe file, not -sync.exe.

    Run the installer

    • Double-click the downloaded file. Do not use “Run as administrator”: NVM for Windows installs for your user, and an admin install sets it up for the wrong account.
    • Click through with the default options.
    • If it finds an existing Node.js, it asks whether to Adopt or Drop it. Choose Adopt: it moves your old Node into nvm and removes the separate install. A leftover Node.js from nodejs.org is the most common cause of Windows setup problems.

    Close every PowerShell / Terminal window, then open a new PowerShell (Start menu → type “PowerShell” → open it normally, not as administrator).

    Check it worked:

    PS> nvm env

    Expected: it prints nvm's configuration. If you see “nvm is not recognized”, see troubleshooting.

  2. Install Node.js 24

    In the new terminal:

    nvm install 24 nvm alias default 24

    The second line makes Node 24 the default in every new terminal. Check:

    node -v npm -v

    Expected: v24.x.x, then a version number for npm.

    In the new PowerShell:

    PS> nvm install 24 nvm use 24

    nvm use 24 makes Node 24 the default. Check:

    PS> node -v npm -v

    Expected: v24.x.x, then a version number for npm.

    If npm -v says “running scripts is disabled on this system”, run this once, then try again:

    PS> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

    Answer Y if asked. It only affects your user account. If your company laptop blocks it, type npm.cmd wherever this page says npm.

  3. Get the workshop code

    You need Git. Check with git --version. If it's “not recognized”, install Git for Windows with the default options, then open a new PowerShell.

    Clone the repo into your home folder and install everything in one go. This is the only big download:

    cd ~ git clone https://github.com/sayed-imran/ubucon-india-2026.git cd ubucon-india-2026 npm install
    PS> cd ~ git clone https://github.com/sayed-imran/ubucon-india-2026.git cd ubucon-india-2026 npm install

    Expected: npm install ends with “added … packages”. A few “warn” lines are normal; an “ERR!” line is not. It fills one shared node_modules for all five phases.

    No Git? Download the ZIP, extract it into your home folder as ubucon-india-2026, open a terminal in it and run npm install.

  4. Python for phase 05

    needed for the agent tools

    Phase 05 runs a small Python service on your laptop that lets the agent open apps and links. It needs Python 3.10 or newer.

    sudo apt install -y python3 python3-venv python3 --version

    Expected: Python 3.10 or newer. Ubuntu 22.04 ships 3.10 and 24.04 ships 3.12.

    python3 --version

    If it prints 3.9 or lower (Apple's built-in Python), install Python 3.12 from python.org or with brew install python@3.12, then open a new terminal.

    PS> py --version

    If it's not recognized or older than 3.10, install Python 3.12 from python.org. On the first installer screen, tick “Add python.exe to PATH”. Then open a new PowerShell.

    Install the service's packages. This also starts the service once; when it's running, stop it with Ctrl+C:

    cd ~/ubucon-india-2026/phase-05/tools-service ./start.sh
    PS> cd ~\ubucon-india-2026\phase-05\tools-service .\start.cmd

  5. Check it all works

    cd ~/ubucon-india-2026/phase-01 npm run dev
    PS> cd ~\ubucon-india-2026\phase-01 npm run dev

    Open http://localhost:3000, click Start listening, allow the microphone and say something. The speech meter should move. Stop the server with Ctrl+C.

    All set. At home, the DGX Spark status in the app's header stays red. That's expected: it turns green once you're on the workshop network.

If something goes wrong

nvm: command not found after installing nvm

Open a new terminal first. If it still fails, load nvm by hand, then check that your shell profile (~/.bashrc, ~/.zshrc or ~/.bash_profile) contains the nvm lines the installer printed:

export NVM_DIR="$HOME/.nvm" . "$NVM_DIR/nvm.sh" nvm --version

On macOS, if ~/.zshrc didn't exist, the installer had nowhere to write. Run touch ~/.zshrc, then run the nvm install command again.

node -v shows an old version in a new terminal

Run nvm alias default 24, then open a new terminal. A Node installed with apt, Homebrew or the nodejs.org installer can also come first on your PATH: which node should point inside ~/.nvm.

./start.sh fails with “ensurepip is not available” or a venv error

Ubuntu ships venv as a separate package. Install it, delete the half-made .venv folder and run ./start.sh again:

sudo apt install -y python3-venv rm -rf .venv ./start.sh
nvm is not recognized after installing

Close all PowerShell and Terminal windows (and VS Code, if you use its terminal) and open a new one. The installer updates your PATH, but windows that were already open don't see the change. If it still fails, sign out of Windows and back in.

node -v still shows an old version, or nvm use doesn't change it

An older Node.js installed from nodejs.org is still on your PATH. Go to Settings → Apps → Installed apps, uninstall “Node.js”, then open a new PowerShell and run nvm use 24 again. Running the nvm installer again also offers to Adopt or Drop it.

“running scripts is disabled on this system”

Run Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned once. If your company laptop blocks that, use npm.cmd instead of npm, for example npm.cmd install and npm.cmd run dev.

Typing python opens the Microsoft Store

That's a Windows placeholder, not real Python. Install Python from python.org with “Add python.exe to PATH” ticked, then open a new PowerShell. start.cmd uses the py launcher when it's available.

npm install fails with network or permission errors

Network errors: you're probably behind a proxy or a Wi-Fi login page. Try another network, then run npm install again. Permission errors (EACCES): you're likely using a system Node, not nvm's. Check that node -v prints v24, and never use sudo npm.

Port 3000 is already in use

Another app is using it. Stop that app, or run phase 01 on another port with npm run dev -- --port 3100 and open that port instead.

Bring headphones: a room full of laptops talking out loud gets noisy.
